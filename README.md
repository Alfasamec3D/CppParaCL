# CppParaCL

Интерпретатор языка ParaCL на C++ с AST на базе `INode` / `Node` и фронтендом FLEX + BISON.

## Возможности

- ✅ Арифметические операции: `+ - * / %`
- ✅ Операции сравнения: `== != < > <= >=`
- ✅ Логические операции: `&& || !`
- ✅ Управляющие конструкции: `if`, `while`
- ✅ Ввод/вывод: `input`, `output`
- ✅ Вложенные области видимости
- ✅ Автоматическое объявление переменных

## Зависимости

- CMake >= 3.16
- C++17 компилятор
- `flex`
- `bison`

```bash
sudo apt install build-essential cmake flex bison
```

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/paracl examples/hello.pcl
```

## Тестирование

Проект включает 10 тестов, покрывающих лексер, парсер и интерпретатор:

```bash
ctest --test-dir build
```

Тесты проверяют:
- Базовые операции (арифметика, сравнения, логика)
- Управляющие конструкции (if, while)
- Вложенные области видимости
- Обработку ошибок (необъявленные переменные)

## Структура проекта

| Путь | Назначение |
|------|------------|
| `include/INode.hpp` | Интерфейсы AST узлов и перечисление операций |

| `tests/` | Набор тестов для проверки функциональности |

## Архитектура

### AST (Abstract Syntax Tree)

Дерево строится из узлов, реализующих интерфейс `INode`:

- **Value** — целочисленный литерал
- **Decl** — переменная
- **Scope** — область видимости с таблицей переменных
- **Op** — бинарная/унарная операция
- **If** — условный оператор
- **While** — цикл

### Управление памятью

- `Scope` владеет всеми переменными (`Decl`) и вложенными узлами
- Деструкторы операторов проверяют тип узла перед удалением
- Переменные не удаляются операторами, только `Scope`

### Парсер

BISON строит AST "на лету" через фабричные функции:
- `make_value(int)` — создать литерал
- `make_op(left, op, right)` — создать операцию
- `make_if(condition, body)` — создать if
- `make_while(condition, body)` — создать while
- `create_scope()` — создать корневую область видимости

## Синтаксис ParaCL

```paracl
// Присваивание
x = 10;
y = 20;

// Вывод
output x + y;

// Условие
if (x < y) {
    output x;
}

// Цикл
i = 0;
while (i < 5) {
    output i;
    i = i + 1;
}

// Ввод
x = input;
output x * 2;

// Вложенные области видимости
{
    local_var = 42;
    output local_var;
}
```

## Примеры

### Арифметика
```bash
./build/paracl tests/test_operators.pcl
# Вывод: 13 7 30 3 1
```

### Циклы
```bash
./build/paracl tests/test_while.pcl
# Вывод: 0 1 2 3 4 55
```

### Условия
```bash
./build/paracl tests/test_comparisons.pcl
# Вывод: 1 3 4 5 6
```

## Ограничения

- Только целочисленная арифметика
- Нет массивов и функций
- Нет `else` ветки для `if`
- Нет обработки деления на ноль
- Переменные объявляются автоматически при первом присваивании
